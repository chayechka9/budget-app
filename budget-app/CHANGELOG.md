# Changelog

Журнал для следующей ИИ-сессии: что менялось в проекте и почему. Новые записи — сверху.

## 2026-08-17 — Add an AI insights and Ireland-personalization vision to the roadmap
Что: в product-roadmap-and-checkpoints.md обновлён главный мотив («и как распределять
их грамотно»), добавлен AI insights в список Pro-функций и новый раздел 10 —
Weekly Money Brief / "Can I afford X?" через LLM (платная Pro-функция), Ireland как
первый рынок с принципом core/country-module архитектуры на будущее (без рефакторинга
сейчас), ирландский налоговый блок (Income Tax/USC/PRSI) явно отложен.
Почему: пользователь хочет чуть более персонализированный продукт под ирландский рынок
и AI-инсайты как отдельный поздний платный этап, а не просто generic budget tracker.

## 2026-08-17 — Add a changelog rule for AI context handoff
Что: в `AGENTS.md` добавлен раздел, требующий после каждого коммита дописывать запись
в этот файл — что изменилось и почему.
Почему: чтобы новая ИИ-сессия без памяти о предыдущей работе быстро понимала контекст
проекта, не пересобирая его заново.

## 2026-08-17 — Make CLAUDE.md check the installed Expo version instead of hardcoding SDK 57
Что: `CLAUDE.md` больше не называет конкретную версию SDK (была захардкожена SDK 57),
теперь требует проверять фактическую версию из `package.json` перед работой; убрана
устаревшая историческая справка про откат на SDK 54.
Почему: захардкоженная версия быстро устаревает и вводит агента в заблуждение;
историческая справка была разовым эпизодом и потеряла актуальность.
