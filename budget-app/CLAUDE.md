# Expo — проверяй актуальную версию

У Expo часто меняется API между SDK. Не пиши код по памяти из обучения — она может быть
устаревшей.

Перед работой:
1. Проверь фактическую версию Expo в проекте: `"expo"` в `package.json`, либо `npx expo --version`.
2. Прочитай точную версионную документацию под неё: https://docs.expo.dev/versions/vX.Y.0/
   (подставь установленную мажорную.минорную версию).

Не меняй SDK-версию проекта без явного запроса пользователя.
